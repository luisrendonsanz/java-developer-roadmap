# Semana 1 — Fundamentos de Java

## Meta de la semana

Terminar la semana pudiendo escribir programas pequeños en Java sin depender de copiar código de un tutorial.

## Temas

### Día 1 — Cómo funciona Java
- JDK, JVM y JRE
- compilar y ejecutar
- estructura de una clase
- `main`
- `System.out.println`

### Día 2 — Variables y tipos
- `int`, `long`, `double`, `boolean`, `char`
- `String`
- conversión de tipos
- operadores aritméticos y lógicos

### Día 3 — Condicionales
- `if`
- `else if`
- `else`
- `switch`

### Día 4 — Bucles
- `for`
- `while`
- `do while`
- `break`
- `continue`

### Día 5 — Métodos
- parámetros
- retorno
- sobrecarga
- scope

### Día 6 — Arrays + práctica
- arrays
- recorrer arrays
- búsqueda
- máximo / mínimo
- promedio

### Día 7 — Mini proyecto
Crear una aplicación de consola llamada **StudentGradeManager**.

Debe permitir:

1. registrar calificaciones;
2. mostrar todas las calificaciones;
3. calcular promedio;
4. mostrar calificación máxima;
5. mostrar calificación mínima;
6. indicar cuántos alumnos aprobaron;
7. salir del programa.

## Definition of Done

La semana termina cuando:

- [ ] puedes explicar JDK vs JVM;
- [ ] sabes cuándo usar `if`, `switch`, `for` y `while`;
- [ ] puedes crear métodos con parámetros y retorno;
- [ ] puedes recorrer y manipular un array;
- [ ] terminaste al menos 20 ejercicios;
- [ ] StudentGradeManager funciona;
- [ ] todo está versionado con Git.

## Regla

Cuando te atasques:

1. intenta resolverlo 20–30 minutos;
2. reduce el problema a una versión más pequeña;
3. usa el debugger o imprime valores;
4. busca solamente el concepto que te falta;
5. vuelve a escribir la solución por tu cuenta.
